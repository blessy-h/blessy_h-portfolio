MIA PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the mia_portfolio_site folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

BEFORE PUBLISHING
- Replace your.email@example.com with your real professional email in index.html.
- Replace the LinkedIn and GitHub links with your profile URLs.
- Add a real resume PDF and link the header button to it if you want a downloadable resume.
- Add live URLs to your projects when they are published.
- Review all profile details for accuracy.

FILES
index.html       Website content
style.css        Pastel design and responsive styling
script.js        Mobile menu and interactive card effects
assets/          Profile portrait and decorative trophy icon

The website uses Google Fonts when internet access is available; fallback fonts are included.
